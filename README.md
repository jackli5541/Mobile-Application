# 移动应用开发课程作业

本仓库用于存放“移动应用开发”课程的作业代码与实践内容。

项目基于 Vue 3、Quasar 和 Vite 开发，各章节作业将按课程进度持续整理和更新。

## 本地运行

```bash
npm install
npm run dev
```

## 构建与预览

```bash
npm run build
npm run preview
```

## 大实验一

运行开发服务器后访问 `/#/big-task01`，或从侧栏进入“大实验一：文章搜索与组件封装”。
包含文章数据生成、标题与作者实时搜索、清空、点击提示、点赞和刷新，页面显示李亚鸿及学号 24211860108。

报告填写文字、代码粘贴顺序和截图说明见 [报告填写说明](docs/experiment1/报告填写说明.md)，
相关源码汇总见 [实验代码汇总](docs/experiment1/实验代码汇总.md)，实测截图存放在 `docs/experiment1/screenshots/`。
